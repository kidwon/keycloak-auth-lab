使用 Keycloak 登录 进入学习面板

一次请求的旅程

  1. 浏览器携带 state 与 S256 challenge 前往 Keycloak。
  2. 服务端使用授权码和 verifier 换取令牌。
  3. 网页客户端用 Access Token 调用 API。
  4. API 验证签名、issuer、时间、audience，再判断 scope、角色和归属。

本项目仅用于本地学习。登录后展示安全 claims，不展示可复用凭据。
