ID Token → 客户端

表示本次 OIDC 身份认证结果，aud 是 web-client，不能代替 API 凭据。



Access Token → API
aud 包含 resource-api；scope 决定允许的操作。JWT 是编码与签名，不是加密。


Refresh Token → 服务端
仅保存在服务端内存，用于换取新的 Access Token。不会写入浏览器 localStorage，重启应用后需重新登录。


发起 API 实验
请求从网页服务器发出，只携带 Access Token。Alice 读取订单 2 返回 403；Admin 可读取全部订单。用户令牌调用机器端点返回 403。







观察协议
授权请求：response_type=code、state、code_challenge、code_challenge_method=S256。
换码请求：服务端 POST 表单，包含 code 与 code_verifier；不要将真实值写入日志或截图。
401 表示凭据无效或缺失；403 表示已通过认证，但授权不足。身份主键使用 iss + sub。




注销不使已签发 JWT 立即失效；实验中 Access Token 生命周期为 120 秒。
