リクエストの流れ

  1. ブラウザーが state と S256 challenge を付けて Keycloak にアクセスします。
  2. サーバーが認可コードと verifier をトークンに交換します。
  3. Web クライアントが Access Token を使って API を呼び出します。
  4. API が署名、issuer、時刻、audience を検証し、scope、ロール、所有権を確認します。

ローカル学習専用のプロジェクトです。ログイン後は許可された claims のみ表示し、再利用可能な認証情報は表示しません。
